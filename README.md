# 🧩 Extensions App Instructions

## 👋 Welcome!

In the Frontend course you will build **one app**, the Extensions Manager, in three versions. Each version adds more to the same project.

This repo has the instructions for Versions 1 to 3. The code you build lives in your own copy of the [`extensions-app`](https://github.com/ac-frontend/extensions-app) repo.

## 🚀 The Roadmap

| Version | What you build | What you practice |
| ------- | -------------- | ----------------- |
| 1 | Show the extensions as cards | Objects and arrays, JSX, `.map()` |
| 2 | Make the app interactive | Components, props, state, toggle, remove, filter |
| 3 | Add extensions, light and dark mode, load data from an API | Forms, `useEffect`, `fetch`, deploying |

Each version has 2 or 3 **checkpoints**. At each checkpoint you commit your work, push it to GitHub, and deploy it to Netlify.

You keep working in **one repo** the whole time. There are no copies of your project.

## 📝 Tips for building your project

1. **Pseudo-code before you write any code!** Use the `pseudo-code.txt` file in each version folder.
2. **Work on one feature at a time.** Test in the browser as you go.
3. **Comment your code.** You will build on it for weeks.
4. **Clean up as you go.** Rename confusing variables and remove unused code.
5. **Commit often, with meaningful messages.** See below.

## ✍️ Writing commit messages

A commit message tells your future self, and anyone reading your repo, what changed. Start with a verb and say what you did.

| ❌ Not helpful | ✅ Helpful |
| --- | --- |
| `update` | `Add Card component that shows logo, name and description` |
| `fix` | `Fix remove button deleting the wrong card` |
| `stuff` | `Filter extensions by active status` |

Commit every time one small thing works, not once at the end.
